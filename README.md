## 🚀 Featured Projects

### 🧠 Intelligent Pricing Engine
> TypeScript · Node.js · PostgreSQL · Clean Architecture · DDD

An anchor-first dynamic pricing microservice for hospitality SaaS.
Evaluates 4 pluggable formula strategies (competitor-based, 
occupancy-driven, multi-factor, demand-driven) across every 
room type × rate plan × date. Full JSONB explainability trace 
+ confidence scoring on every recommendation.

**Key highlights:**
- PostgreSQL advisory locks → zero overlapping runs
- Unit of Work pattern → transactional safety
- node-cron scheduler → nightly pricing for all properties
- ≥80% Vitest test coverage

---

### 📊 Revenue Management System
> React 19 · Redux Toolkit · Express 5 · PostgreSQL · PrimeReact

A revenue manager's daily cockpit — 13 feature modules for 
pricing strategy, guardrails, dashboards, benchmarks and reports.

**Key highlights:**
- Bulk rate-publish pipeline → Promise.allSettled + 
  exponential backoff retry (2s→4s→8s→30s)
- Global publish-job poller → live toast progress across SPA
- Multi-tenant Postgres RLS → SET app.current_tenant
- 3 pivot views: room-type / rate-plan / summary

---

### 🌐 Internet Booking Engine (IBE)
> React 19 · Vite SSR · PWA · Workbox · TanStack Query · Playwright

SSR + PWA hotel booking site with offline cart support.

**Key highlights:**
- <2.5s LCP · WCAG 2.2 AA · 7 locales
- PCI DSS SAQ-A compliant payments with 3DS2 SCA
- Workbox background sync → offline-first experience
